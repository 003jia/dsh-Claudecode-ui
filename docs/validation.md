## 构建与复核

公开仓库包含上述25项单元检查。准备好匹配的DSH源码后运行：

```sh
export DSH_SOURCE=/absolute/path/to/deepseek-harness
npm run build
npm test
```

真实 Loader 集成与图库由维护者在匹配的DSH测试环境执行。不同构建目录会产生不同的CSS Modules名称和源码映射路径；发行附件使用通过集成与图库验证的同一份预构建文件，不声称跨目录构建字节恒定。

发行附件同时提供 `SHA256SUMS.txt`，可在下载目录验证：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
