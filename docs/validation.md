## 构建与复核

公开仓库包含上述25项单元检查。准备好匹配的DSH源码后运行：

```sh
export DSH_SOURCE=/absolute/path/to/deepseek-harness
npm run build
npm test
```

隔离 Loader 与图库由维护者在匹配的 DSH 测试环境执行。构建目录可能影响 CSS Modules 类名；发行附件使用通过集成和图库验证的预构建文件。

发行附件同时提供 `SHA256SUMS.txt`，可在下载目录验证：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
